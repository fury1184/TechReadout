TechReadOut v3.7.0 — Inventory Breakdown + lookup-flow fixes
================================================================

Files in this patch (paths relative to repo root):

  app/routes/stats.py               NEW — /stats Inventory Breakdown page.
                                     Groups owned inventory by socket, chipset,
                                     type, capacity, manufacturer, VRAM,
                                     interface, wattage, and form factor per
                                     component type. Sums Inventory.quantity
                                     (not row count). Normalizes known messy
                                     socket variants (e.g. "LGA 2011-3" vs
                                     "LGA 2011-v3") before grouping via
                                     VALUE_ALIASES — a display-time patch;
                                     the underlying hardware_specs data is
                                     untouched. Custom inventory entries with
                                     no resolved hardware_spec_id are rolled
                                     into an "Unknown / custom entry" row.

  app/templates/stats.html          NEW — template for the above.

  app/__init__.py                   Registers the new stats blueprint
                                     (no url_prefix, matches main.bp).

  app/templates/base.html           Adds "Inventory Breakdown" sidebar link
                                     pointing at stats.stats.

  app/templates/inventory/add.html  - Manual Entry Mode no longer persists via
                                       localStorage across page loads. It was
                                       silently carrying over between sessions
                                       and could cause a lookup to be skipped
                                       with no error shown. Now always starts
                                       unchecked; the toggle only affects the
                                       current page view.
                                     - Closing the low-confidence review modal
                                       (Cancel or X) without picking a
                                       candidate used to leave a frozen
                                       "please review below" banner with no
                                       way forward. A new hidden.bs.modal
                                       listener now falls back to showing
                                       manual entry + the AI Import
                                       suggestion on the main form when no
                                       spec was applied.

  app/routes/main.py                review_save() dedup now compares
                                     LookupCache.normalize_query() (lowercase,
                                     collapsed whitespace) instead of an exact
                                     string match, so a retry like "gt 730"
                                     after an earlier "MSI GT 730" collapses
                                     into the same pending row instead of
                                     spawning a duplicate that looks "stuck"
                                     after the first is skipped/accepted.
                                     Stored/displayed query text is unchanged
                                     — only the comparison is normalized.
                                     Existing near-duplicate rows already in
                                     the queue are NOT retroactively merged;
                                     this only affects new saves going
                                     forward, per request.

  app/version.py                    APP_VERSION bumped 3.6.1 -> 3.7.0.

  README.md                         Changelog, Features, and Project
                                     Structure sections updated for v3.7.0
                                     and (retroactively) v3.6.0. Also
                                     consolidated three ad-hoc version blurbs
                                     that had been prepended above the title
                                     instead of living in the Changelog
                                     section — no content changed, just
                                     relocated to their chronological slot.

To apply: copy all files above over the matching paths in your working tree.
No rebuild needed — the ./app bind mount picks up template/route changes,
and Flask's debug reloader restarts the dev server automatically on save
(needed here since app/__init__.py changes which blueprints are registered
at process start).

Not included in this patch: the docker-compose.yml volumes: entry for
mounting Core-One's SMB share (host-specific, applied directly on Locust)
and any cleanup of pre-existing duplicate PendingReview rows in the queue
(explicitly deferred — only new saves are deduped going forward).
