Deploy
------
  1. Edit the server's .env: add DB_ROOT_PASSWORD, DB_PASSWORD, SECRET_KEY
     and TZ (see .env.example). DB_PASSWORD must match the existing
     techreadout DB user's password (old default: techreadout).
  2. WinSCP Synchronize (Local -> Remote) onto /opt/stacks/techreadout/
  3. docker compose up -d --build --force-recreate
  Rebuild required (Dockerfile changed). No schema change, no migration.

Verify
------
  1. Footer/dashboard shows TechReadOut v3.8.17.
  2. docker compose logs app shows gunicorn workers starting, not the
     Flask development server warning.
  3. The app connects to the database and loads the dashboard.
  4. Port 3306 is no longer reachable from outside the host.
