Deploy
------
  1. Run migrations/v3.10.0_current_value.sql against the live database
     BEFORE syncing code (adds inventory.current_value,
     inventory.current_value_updated_at -- nullable, additive, no backfill
     needed).
  2. WinSCP Synchronize (Local -> Remote) onto /opt/stacks/techreadout/
  3. docker restart techreadout-app
     (route/template/model changes only -- no rebuild needed.)

Verify
------
  1. Footer/dashboard shows TechReadOut v3.10.0.
  2. Inventory item detail: "Purchase Price" and "Current Value" show as
     separate rows; "Fetch eBay Price" -> Apply updates only Current Value.
  3. Edit an item's Current Value manually; confirm the eBay-estimate
     badge clears and Purchase Price is untouched.
  4. A host with assigned, current-value-priced components shows the
     updated total under "Estimated Current Value" on its detail page,
     the Hosts list, and Compare Hosts.
  5. Dashboard "Inventory Value" still shows a sensible total for items
     that only have a purchase_price (no current_value fetched yet).
  6. Lookup Settings page's "What changed in v3.10.0" card describes
     current_value, not the old v3.9.0 password-login text.
