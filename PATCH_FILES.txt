Deploy
------
  1. WinSCP Synchronize (Local -> Remote) onto /opt/stacks/techreadout/
  2. docker compose restart app
  3. docker exec techreadout-app python -m app.maintenance.backfill_storage_interfaces
     (dry run -- review the list, then re-run with --apply to commit)
  No schema change, no migration, no rebuild.

Verify
------
  1. Locally: python -m pytest  -> 267 passed.
  2. Footer/dashboard shows TechReadOut v3.8.13.
  3. Run the backfill script (see Deploy step 3) and confirm the printed
     changes look right, in particular that any "SATA 3.0 Gbps" row maps
     to "SATA II", never "SATA III".
  4. /stats Storage "By Interface": the old split rows (SATA III / SATA III
     6Gb/s / SATA 6.0 Gbps, and M.2 NVMe PCIe 4.0 x4 / PCIe 4.0 x4) are now
     merged into single rows with combined quantities.
  5. Add Inventory with a custom/manual storage entry whose interface you
     type as "SATA 6.0 Gbps" -- after saving, open the spec and confirm it
     was stored as "SATA III".
  6. Open any inventory item's detail page: a "Delete" button appears next
     to Edit/Split/Back; confirming it removes the item and returns to
     /inventory.
  7. Open any inventory item's Edit page: a "Delete Item" button appears
     below Save Changes; confirming it removes the item and returns to
     /inventory.
