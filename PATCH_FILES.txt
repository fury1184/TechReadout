TechReadOut 3.5.13 - Component Type Editing Patch
=================================================

Applies over: TechReadOut 3.5.12
Database migration: NOT required

Changed files:
  app/version.py
  app/spec_editor.py
  app/routes/main.py
  app/templates/specs/edit.html

Changes:
- General Hardware Spec Editor now allows changing Component Type.
- Selecting another type reloads the editor with that type's relevant fields.
- Saving a component-type change clears stale fields belonging to other types.
- All inventory rows linked to the shared HardwareSpec are updated to the corrected component type.
- Type changes are recorded in the existing manual-edit metadata, including old/new type and cleared fields.
- Version updated to 3.5.13.

Install:
1. Back up your current TechReadOut folder/database.
2. Extract this zip over the TechReadOut 3.5.12 application root, preserving paths.
3. Rebuild/recreate the app:

   cd /opt/stacks/techreadout
   docker compose up -d --build --force-recreate

4. Hard-refresh the browser (Ctrl+F5).
