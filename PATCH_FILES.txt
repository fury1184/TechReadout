Deploy
------
  1. WinSCP Synchronize (Local -> Remote) onto /opt/stacks/techreadout/
  2. Optional: add APP_PASSWORD=... to .env on the server.
  3. docker compose up -d --force-recreate app
     (compose file changed, so a plain docker restart is not enough.)
  No rebuild, no schema change, no migration.

Verify
------
  1. Footer/dashboard shows TechReadOut v3.9.0.
  2. With APP_PASSWORD set: opening any page lands on /login; a wrong
     password is rejected; the right one opens the dashboard and the
     sidebar shows Log out.
  3. With APP_PASSWORD empty: no login page, no Log out link.
