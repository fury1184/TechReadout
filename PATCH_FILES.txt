Deploy
------
  1. WinSCP Synchronize (Local -> Remote) onto /opt/stacks/techreadout/
  2. docker restart techreadout-app
  3. Lookup Cache page -> Clear misses (once; most were caused by the Google block)
  No schema change, no migration, no rebuild.

Verify
------
  1. Locally: python -m pytest  -> 172 passed.
  2. Watch the log while testing lookups:
       docker logs -f --tail 0 techreadout-app 2>&1 | sed -u -E 's/token=[^&[:space:]"]+/token=***/g'
  3. RAM lookup "ADATA XPG DDR4-2400 CL16": the log shows Newegg search, then
     Amazon search picking XPG Z1 DDR4 2400 (AX4U240038G16-DRZ), with a
     "cost 1 credit(s)" line per call. Result: DDR4, 2400, CL16, 16GB, 2 sticks.
  4. RAM lookup "Team T-FORCE VULCAN Z 32GB DDR4-3200": found on Newegg (2 calls).
  5. An ASUS motherboard lookup logs "ASUS official site skipped" and goes
     straight to Newegg.
  6. Sell 1 of a quantity-2 item: one Sold row + one remaining row, no error.
  7. Lookup Settings -> Check Balance: "X of Y credits remaining", matching
     the Scrape.Do dashboard.
  8. Inventory Breakdown: sold/dead parts gone from the counts; a 2x16GB kit
     shows 2 under Stick Size 16.
  9. Open any build plan: the page loads. A plan with socket LGA 2011 no
     longer lists LGA 2011-3 CPUs or X99 boards; a plan using 2 sticks from
     an 8-stick row shows 2 sticks' worth of RAM.
 10. docker logs techreadout-app 2>&1 | grep -c "token="  (see Upgrade note)
