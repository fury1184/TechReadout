  (Unchanged from the earlier 3.8.10 zip -- skip if already done.)

Deploy
------
  1. WinSCP Synchronize (Local -> Remote) onto /opt/stacks/techreadout/
  2. Make the docker-compose.yml change above (if not already done).
  3. docker compose build app        (new tzdata package)
  4. docker compose up -d app        (starts the new image with TZ)
  5. Run the GPU-manufacturer backfill (fixes any existing specs saved with
     an AIB brand as manufacturer -- see CHANGELOG):
       docker exec techreadout-app python -m app.maintenance.backfill_gpu_manufacturer
     Review the dry-run output, then:
       docker exec techreadout-app python -m app.maintenance.backfill_gpu_manufacturer --apply
  No schema change, no migration.

Verify
------
  1. Locally: python -m pytest  -> 235 passed.
  2. docker exec techreadout-app date   -> shows your local time zone.
  3. Dashboard: the two RAM sticks added the evening of Sept 28 show 2026-09-28.
  4. Add Inventory: look up "EVGA GTX 1660" with the Manufacturer field blank
     -> field fills with "EVGA", not "NVIDIA". Look it up again with
     Manufacturer already set to something -> it's left alone.
  5. /stats -> GPU -> By Manufacturer shows only NVIDIA/AMD/Intel rows (no
