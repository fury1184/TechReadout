TechReadOut patch — NAS backup path editable from the app (no version bump)
================================================================

Files in this patch (paths relative to repo root):

  app/routes/backup.py             - Added AppSetting import.
                                    - New get_nas_path() resolver: prefers
                                      AppSetting('nas_backup_path'), falls
                                      back to the NAS_BACKUP_PATH env var for
                                      existing setups that already have it in
                                      docker-compose.yml/.env.
                                    - New POST /backup/nas-path route
                                      (update_nas_path) — saves the path via
                                      AppSetting.set(), warns (but doesn't
                                      block) if the path isn't visible inside
                                      the container yet.
                                    - index() and create_backup() now call
                                      get_nas_path() instead of referencing
                                      the old module-level NAS_PATH constant.
                                    NOTE: this only changes *where within an
                                    already-mounted volume* backups are
                                    written. The NAS share itself still needs
                                    a `volumes:` entry in docker-compose.yml
                                    to be reachable from inside the
                                    container — this patch doesn't add or
                                    change any mount.

  app/templates/backup/index.html  Replaced the static "edit
                                    docker-compose.yml" alert with an inline
                                    "NAS Backup Path" card — a text field +
                                    Save button, pre-filled with the current
                                    path, with a note about the volume-mount
                                    requirement above.

To apply: copy both files over the matching paths in your working tree, then
docker compose up -d --build --force-recreate.

This patch was NOT versioned as its own release, and is kept separate from
the other pending patches (3.6.1 sidebar fix, JSON export/CSV fix) per your
request.
