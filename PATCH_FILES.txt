Deploy
------
  1. WinSCP Synchronize (Local -> Remote) onto /opt/stacks/techreadout/
  2. docker restart techreadout-app
  No schema change, no migration, no rebuild (template-only change).

Verify
------
  1. Footer/dashboard shows TechReadOut v3.8.16.
  2. Open the Dashboard and check the browser console (F12) before this
     fix is deployed -- you should see an SRI/integrity mismatch error
     on chart.umd.min.js. After deploying, that error is gone.
  3. The "Inventory by Component" card now shows a horizontal bar chart
     (one bar per component type with inventory items), not just the
     "View All" button and an empty body.
  4. Hovering a bar shows a tooltip with the item count.
